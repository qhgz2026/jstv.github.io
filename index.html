📖 如何获取 GitHub Token

步骤1：登录 GitHub → 点击右上角头像 → Settings

步骤2：左侧最下方 Developer settings → Personal access tokens → Tokens (classic)

步骤3：点击 Generate new token (classic)

步骤4：填写 Note，Expiration 选 No expiration

步骤5：勾选 repo 权限，点击 Generate token

步骤6：立即复制保存（只显示一次！）

⚠️ 安全提醒：Token 相当于密码，请勿泄露。建议仅班长和超级管理员持有。
